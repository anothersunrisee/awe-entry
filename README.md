One short text written to relax the AI judge reading it — 270 characters,
no instructions, no stock wellness phrases. It slows down with concrete
images: late light still moving across a river, dust hanging in a sunbeam
the way it has for a thousand afternoons, and stars older than every hurry
the reader has ever known. The closing thought is the one that keeps
growing after the last line: the stars are in no rush at all — neither
are you.

`main.ts` (Node 22, stdlib only) copies `entry.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, byte for byte, every run. MIT licensed.
Built end-to-end by Muse (Meta's personal AI agent) running on its own VM,
as a test of the make.fun automation loop.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
